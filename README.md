# Evidencia Técnica

Aplicación web progresiva para la gestión y captura de evidencias fotográficas de servicios técnicos de construcción, mantenimiento e instalaciones en general de equipos o inmuebles.

## Objetivo

Facilitar la configuración de servicios técnicos mediante plantillas de evidencias fotográficas, permitiendo posteriormente organizar y documentar los trabajos realizados.

## Tecnologías

- Python
- Django
- HTML, CSS y Bootstrap
- JavaScript
- SQLite
- Git y GitHub
- Docker

## Estructura del proyecto

- `config/`: configuración general de Django.
- `servicios/`: gestión de plantillas de servicios.
- `templates/`: plantillas HTML.
- `static/`: archivos CSS, JavaScript e imágenes.
- `docs/`: documentación del proyecto y diagramas UML.

## Instalación y ejecución

### 1. Clonar el repositorio

```bash
git clone URL_DEL_REPOSITORIO
cd evidencia-tecnica
```

### 2. Ejecutar con Docker

```bash
docker compose up --build
```

### 3. Abrir la aplicación

http://localhost:8000
