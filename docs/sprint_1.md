# Sprint 1

## Objetivo
Configurar el entorno de desarrollo y desarrollar
la funcionalidad inicial para crear plantillas
de servicios.

## Trabajo seleccionado
- Crear proyecto Django.
- Configurar la aplicación servicios.
- Configurar el entorno Docker.
- Implementar el modelo Servicio.
- Documentar los diagramas UML.

## Criterios de finalización
- La aplicación se ejecuta correctamente.
- Docker permite iniciar el proyecto.
- Se puede registrar una plantilla.
- Se pueden configurar sus pasos fotográficos.
- Los cambios están integrados mediante Pull Request.
